# GitHubCopilotDemo-Cloud
Demo GitHub Copilot App usando modelos Cloud

## 🎉 GitHub Copilot Dev Days — UCV Caracas (2 de octubre de 2026)

Este repositorio contiene una landing page sencilla creada para el evento
**GitHub Copilot Dev Days** en la Universidad Central de Venezuela.

La página se encuentra en:

- [`index.html`](index.html) — estructura de la página
- [`css/style.css`](css/style.css) — estilos
- [`js/script.js`](js/script.js) — cuenta regresiva y formulario de registro

Para verla localmente, abre `index.html` en tu navegador (no requiere
instalación ni dependencias).

### 🐛 Bugs intencionales

Con fines didácticos, esta landing page **contiene errores a propósito**.
La idea es que los estudiantes usen **GitHub Copilot** (Chat, Agents, Code
Review) para encontrarlos y corregirlos. Cada bug está documentado como un
[Issue](../../issues) en este repositorio; ¡resuélvelos con ayuda de Copilot!

- [#2 — El botón "Reserva tu cupo" no tiene estilo](../../issues/2)
- [#3 — La cuenta regresiva muestra la fecha incorrecta](../../issues/3)
- [#4 — El formulario acepta correos electrónicos inválidos](../../issues/4)

### 🤝 Cómo contribuir en la demo

1. Elige un Issue abierto.
2. Pídele a GitHub Copilot que te ayude a diagnosticar y corregir el bug.
3. Abre un Pull Request con la solución para que sea revisado.
